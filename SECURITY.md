# Security policy

The Inkfree MCP server is a hosted service operated by SoftSages. This repository contains
documentation only.

## Reporting a vulnerability

Email **support@inkfree.app** with the subject line `SECURITY: MCP`. Please include:

- what you found and where (tool name, endpoint, or OAuth step)
- steps to reproduce
- the impact you believe it has

Please do not open a public GitHub issue for security reports, and do not access or change data in
accounts you do not own while testing.

We will acknowledge your report within 3 business days and keep you updated until it is resolved.
